# LF · Repo de calificación del agente de Programación (sandbox)

Repo **temporal y no productivo** para calificar el método de la Fase 2 (Programación) del agente LF
antes de usarlo en el repo oficial. Lo que se gradúa es el método, no el código de este repo.

- Debe ser una copia fiel del entorno del producto: mismo stack, mismo CI, mismos linters, misma protección.
- No contiene código de negocio de LF ni datos reales. Nada de aquí se despliega.
- Todo cambio entra por PR. Ningún secreto en el repo (solo `.env.example`).
- El oráculo de las pruebas ciegas vive fuera de este repo.

Plan de referencia: `claude/programacion-fase2-desglose-checkpoints-estandares-2026-10-21.md` (proyecto LF).
Arquitectura del producto: `paulozterra/lf-architecture`.
